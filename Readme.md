# Demo Web Application

## Overview
A clean, maintainable web application demonstrating modern CSS best practices, responsive design, and accessibility features.

## Features
- ✅ Clean HTML with semantic markup
- ✅ Modern CSS with BEM naming convention
- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ CSS variables for easy theming
- ✅ Accessible components with focus states
- ✅ No inline styles
- ✅ Well-documented and maintainable

## Project Structure

## CSS Architecture
This project uses:
- **BEM Naming Convention** for maintainable class names
- **CSS Variables** for consistent theming
- **Mobile-First** responsive design approach
- **CSS Grid & Flexbox** for modern layouts
- **Accessibility** features built-in

See [CSS_ARCHITECTURE.md](CSS_ARCHITECTURE.md) for detailed documentation.

## Getting Started
Simply open `index.html` or `about.html` in a web browser to view the application.
